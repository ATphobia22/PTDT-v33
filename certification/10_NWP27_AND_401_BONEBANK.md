# NWP 27 + IDEM 401 — Bonebank addendum (UNSIGNED)

Companion to `09_CIF_CLOMR_404_BONEBANK_CHECKLIST.md`.

## NWP 27 decision tree (parcel 13101 Bonebank Rd)

1. Is the **primary purpose** aquatic habitat restoration with **net aquatic gain**?  
   - **No** for flood berms / gates / most flood storage → **do not use NWP 27**.  
   - **Maybe** only for a discrete wetland/stream restoration component documented by PE/ecologist.
2. If yes → check current NWP 27 text + Louisville regional conditions + PCN triggers.  
3. Always pair with **IDEM 401** path (general conditions vs individual).  
4. Still complete **IDNR CIF**, **local floodplain**, and **FEMA No-Rise or CLOMR** as applicable.

## IDEM 401 decision tree

1. Does USACE say §404 is required (NWP or individual)?  
   - **No** → 401 usually not driven by 404 (other programs may still apply).  
   - **Yes** → obtain 401 (or qualify under published general certification conditions).
2. Minimal / in-scope → RGP notification or NWP general 401 conditions.  
3. Larger / mitigation / sensitive waters → **individual 401** + pre-filing meeting (≥30 days before app).

## Combined multi-agency order (updated)

1. FIRM + BAFM + wetland screening  
2. USACE JD / path (NWP vs individual; NWP 27 only if restoration fits)  
3. IDEM pre-filing (if individual 401) → 401 application  
4. IDNR CIF + public notice  
5. FEMA No-Rise or CLOMR  
6. Posey County local floodplain permit  
7. Construct → as-builts → LOMR if needed
