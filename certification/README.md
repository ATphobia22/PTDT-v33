## Hard limit (cannot be automated)

Under **Indiana IC 25-31-1**, maps, plans, No-Rise certifications, and floodway engineering submissions that constitute the practice of engineering must be **prepared, certified, and sealed by a registered Professional Engineer**.

This repository provides **UNSIGNED drafts and data packages** only.  
**No file in this folder is a sealed PE instrument.** Applying a seal requires a licensed Indiana PE who has performed or supervised the work.
