# External references (context only — not code authority)

These materials inform practice. They are **not** embedded as automated decision engines.

| Source | Use |
|--------|-----|
| Indiana Floodplain Information Portal (INFIP) | BFE / FARA operational access |
| IDNR Best Available Floodplain Layer (BAFL/BAFM) materials | State regulatory layer context |
| Indiana Drainage Handbook (CBBEL / state PL 329-1995 lineage) | Drainage / ditch administrative context |
| USACE *Plan for the Ohio River Basin 2020–2025* (Planning Assistance to States) | Basin-scale goals; not site hydraulic proof |
| NGS NCAT | Vertical datum transforms (NGVD 29 ↔ NAVD 88) |
| USGS NWIS (e.g. 03378500, 03322000) | Stage/discharge telemetry |
| FEMA Map Service Center / Online LOMC | Effective FIRM + LOMA filing |
| [FEMA BCA Toolkit](https://www.fema.gov/grants/tools/benefit-cost-analysis) | Official BCR for HMA/BRIC |
| [IGIO Elevation](https://elevation.gio.in.gov/) / [IndianaMap](https://www.indianamap.org/) / [Purdue LiDAR](https://lidar.digitalforestry.org/) | Statewide QL2 3DEP access |
| State of Indiana OCDO Data Governance Standard | Optional data-handling alignment for public agencies |

## Visualization preference

Prefer **MapLibre** + open terrain/vector sources already in the app stack. Cesium Ion demos require a token and are not required for regulatory filings.

## Hazus / loss estimation literature

Academic or web-based Hazus-MH studies may inform **screening** loss narratives. Official BRIC BCA still uses the **FEMA BCA Toolkit** (or current FEMA-accepted method), not ad-hoc software BCR claims.
