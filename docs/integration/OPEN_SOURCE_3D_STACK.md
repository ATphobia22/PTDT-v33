# Open-Source 3D Stack Integration

## Reality capture

- Photo-SLAM: camera pose/localization and reality-capture observations.
- 3DGS: static photorealistic scene representation.
- 4DGS: temporal/dynamic scene representation.
- Open3D: point-cloud validation, denoising, normals, and reconstruction.

## Procedural completion

- Infinigen: procedural natural/structural asset generation for visual completion and synthetic data. Generated assets remain explicitly procedural.

## Scene interchange and delivery

- OpenUSD: interchange/render/simulation scene graph.
- I3S/SLPK: heterogeneous 3D geospatial streaming.
- MVT/Planetiler-compatible pipelines: vector tile delivery.
- MapLibre/WebGPU: keyless interactive client rendering.

## Engineering geometry

- CAD/OCCT: optional engineering geometry generation/validation for infrastructure assets.

## Rendering

- Radeon ProRender: optional offline physically based/cinematic validation path.
- Houdini/Solaris: optional procedural/USD authoring environment.

## Dependency rule

No listed tool becomes authoritative. No hosted account or API key is required by the core spatial/evidence system. Proprietary or licensed tools are isolated behind adapters and may be replaced by open alternatives.
