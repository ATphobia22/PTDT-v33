# FEMA BCA Toolkit — streamlined assessment paths

**Full BCA** remains the default for complex mitigation. Streamlined paths still require **cost-effectiveness documentation** under FEMA-approved methods.

## When streamlined may apply

| Path | Criterion (FEMA BCA program guidance) |
|---|---|
| **Project cost < $1 million** | May use simplified / streamlined cost-effectiveness documentation per current FEMA fact sheet |
| **Substantial damage acquisition waiver** | Acquisition of substantially damaged properties may qualify for waiver procedures |
| **Pre-calculated benefits** | Specific project types with FEMA-published pre-calculated benefits (e.g., certain elevations/acquisitions) — confirm current list |

Source hub: https://www.fema.gov/grants/tools/benefit-cost-analysis

## Cost-effectiveness definition

**BCR ≥ 1.0** using FEMA-approved methodology (Toolkit or allowed streamlined method).

## Flood benefits still required conceptually

Even on streamlined paths, the project must show **risk reduction**. For riverine structure work, benefits typically derive from:

- Avoided structure/content damage (depth–damage)  
- Avoided displacement / loss of function  
- Other Toolkit categories as applicable  

Site elevations for PTDT: **BFE 375.0 · LAG 377.2 · FFE 382.5 NAVD88** (+2.2 ft clearance supports LOMA *and* residual risk narrative in BCA).

## PTDT package rules

1. Prefer **full Toolkit** for BRIC competitive narrative when structure value and hydraulic story are complex.  
2. If streamlined is used, store FEMA eligibility basis + any pre-calc worksheet in evidence folder `05_Certification`.  
3. Dual BCR constants (**1.41** / **2.45**) remain **UNVERIFIED_DUAL** until Toolkit or accepted streamlined artifact is SHA-256 sealed.
