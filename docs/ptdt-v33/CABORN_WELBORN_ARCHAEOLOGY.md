# Caborn-Welborn archaeological context — Point Township / Posey County

**Use in PTDT:** cultural-heritage overlay + EHP (Environmental & Historic Preservation) awareness for BRIC/LOMA packages — **not** a hydraulic constraint layer.

## Culture summary

| Item | Fact |
|---|---|
| Culture | **Caborn-Welborn** — Late Mississippian, post–Angel Mounds |
| Date range | ~**A.D. 1400–1700** (protohistoric) |
| Core area | Confluence of **Ohio** and **Wabash** (IN / KY / IL) |
| Character | Decentralized villages; maize agriculture; fishing/hunting; shell-tempered pottery; **no** large platform mounds like Angel |
| Significance | Last major pre-contact Native occupation of southern Indiana before European settlement |

## Primary sites in / near Point Township

| Site | Smithsonian / state ID | Notes |
|---|---|---|
| **Hovey Lake–Klein** | **12 Po 10** | Large fortified village on west bank of Hovey Lake oxbow; ~11.8–30 ac; plaza; bastioned palisade; ~100 houses; occupation ~1400–1650 |
| **Murphy** | **12 Po 1** | Mouth-of-the-Wabash / Sullivan Farm; NRHP 1975 |
| **Ashworth** | **12 Po 7** | Point Township near Hovey Lake / SR 69; NRHP 1985 (~50 ac listed) |
| **Bone Bank** | **12 Po 4** | Wabash bank village; named for 19th-c. eroding graves; early Lesueur work 1828; river erosion continues |

Hovey Lake district is in **Point Township**, Posey County — same township as 13101 Bonebank Road. Approximate Hovey Lake village coords: **37.83°N, 87.95°W**.

## Settlement pattern (Hovey Lake)

- Rectangular wall-trench **wattle-and-daub** houses in shallow basins; clay hearths  
- Large storage pits (enough maize for ~7–12 people/year)  
- Central plaza + enclosing palisade with bastions  
- Outlying cemeteries  

Research directed long-term by Cheryl Ann Munson (Indiana University); GPR used for non-invasive structure detection.
