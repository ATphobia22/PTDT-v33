# Indiana water-related funding map (orientation)

Quick map of programs often confused with each other. Always use official NOFOs / manuals for the filing year.

| Program | Agency | Typical applicants | Use for Bonebank? |
|---------|--------|--------------------|-------------------|
| **LOMA / LOMC** | FEMA | Property owner + PE survey | **Yes** if LAG > BFE natural ground |
| **Floodway / No-Rise** | IDNR Division of Water | Owner + Indiana PE | **Yes** if work in floodway |
| **HMA (BRIC / HMGP / FMA)** | FEMA via **IDHS** | Local/state government subapplicants | Only via eligible **local sponsor** + BCA Toolkit |
| **LARE** | IDNR Fish & Wildlife | SWCD, lake assoc., watershed groups, locals | Only if **public lake/stream** project qualifies |
| **CWI** | ISDA / SSCB | SWCDs and partners via GMS | Watershed sediment/nutrient via district |
| **IDEM 319** | IDEM | Watershed groups | Watershed plans / NPS projects |
| **USACE regulatory** | USACE district | Anyone impacting WOTUS | If wetlands/waters impacted |
