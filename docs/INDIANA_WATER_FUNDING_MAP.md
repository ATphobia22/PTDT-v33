# Indiana water-related funding & regulatory map

| Program / path | Agency | Typical applicants | Bonebank relevance |
|----------------|--------|--------------------|--------------------|
| **LOMA / LOMC** | FEMA | Owner + PE survey | Natural high ground if LAG > BFE |
| **Floodway / No-Rise** | IDNR Water | Owner + Indiana PE + **HEC-RAS** | Required for floodway work |
| **HMA (BRIC/HMGP/FMA)** | FEMA via IDHS | Local/state subapplicants | Via eligible sponsor + BCA Toolkit |
| **LARE** | DNR Fish & Wildlife | SWCD, lake/watershed groups | Public lake/stream projects only |
| **CWI** | ISDA / SSCB | SWCDs & partners (GMS) | Sediment/nutrient via district |
| **Section 319(h)** | IDEM NPS | Nonprofits, gov, universities | Watershed plans & BMPs |
| **Section 205(j)** | IDEM NPS | Public agencies only | Planning only; no implementation |
| **USACE regulatory** | USACE district | Anyone impacting WOTUS | If wetlands/waters impacted |
